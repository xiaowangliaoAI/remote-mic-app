# 公开 G9N9N 语音适配

基线 SayAll `dec29b88683ea3464e863f4908408135818529ca`；供体 Voice Input Buddy
`f51f5c800e6de9e2e9a55be61744c9a40797128b`，GPL-3.0-only。

范围仅为 G9N9N 18D1:9450 的 ATVV 1.0 / 16kHz 按住语音。没有采用供体的音频驱动、UI、普通按键映射、遥测或更新配置。复用 SayAll 的 CoreBluetooth 生命周期、ADPCM、帧处理、Chromecast 语音会话与 MiRemoteV 2ch 出口。

构建显式设置 `SAYALL_ENABLE_PUBLIC_CHROMECAST=1`，不设置私有 Package 路径。
分别执行默认和该开关下的 `swift test --disable-keychain --skip BuildSigningTests`，再运行
`scripts/build-app.sh`；不执行 Installer 或驱动构建。CI 产物仅用于进一步核验，未经过 Apple Developer ID 签名/公证前不能当作可信安装包或正式版分发。

## 必测用例

1. 默认构建：小米候选准入与直接 STREAM_START → AUDIO → STREAM_STOP 基线保持；Google 仍由原默认准入拒绝。运行原有全部相关测试。
2. 公开适配构建：原来源页出现 Chromecast，明确只支持按住语音。当前自定义名“小米遥控器”无需改名；其他任意 BLE 名称不被接受。名称只用于候选，PnP 与能力必须来自同一已连接外设。
   Google 连接页不应要求“再按一下实体键”或显示等待普通键检查；真实连接后才可继续，后续仍必须验证音频和真实文字。
3. 两种回调顺序：先身份/后能力和先能力/后身份均在两项齐备后才 Ready。短 PnP、错误编号、8kHz、未知协议或超大帧不 Ready。
4. 保留正式 App 与驱动，测试版使用独立 Bundle ID 和配置；正式版退出后再启动测试版，不同时占用遥控器。首次授权由用户本人完成，不关闭 Gatekeeper、不移除隔离属性或加入受信任根证书。
5. 选择已存在的 MiRemoteV 2ch，不安装驱动。观察真正语音样本和虚拟麦克风电平，不能只看设备存在。
6. 按住说中文，松开结束，连续三轮；确认首字、尾字、结束后的 Fn 释放与输出排空。缺字、继续录音、声音失真或丢失停止均为失败。
7. 第三方识别工具选择相同麦克风，在 SayAll 真实语音测试框确认中文上屏，再在普通 Mac 输入框复测；手打与粘贴不能通过门禁。
8. 断连、取消、超时、重连、10秒以上讲话后检查保活定时器停止，无多余语音启动。不得把保活请求写出等同于遥控器接受或长时录音验收成功。
